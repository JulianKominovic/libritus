# Recommendations and Apparitions

## Recommendations

Recommendations are a way to show users content that is similar to the content they have already consumed inside a category.

For example, we can show him some related books or articles to every book or article he has already added to his library. Also, if the book he is currently reading has sequels or prequels, we can show them.

## Apparitions

Apparitions is something different. We can scan the PDF, extract texts and citations, and then show them to the user as a new content to read later.
